# ✦ VINYL MATRIX — Digital Sound Codex & Turntable Lab

> Интерактивный веб-портал об истории винилового звука, революции формата Long Play (LP 33⅓), рекорде бестселлера *Thriller* Майкла Джексона, физике микроканавки и RIAA-эквализации со встроенной физической вертушкой на Web Audio API.

---

## ⚡ Особенности и функционал (Features)

1. **Интерактивный виниловый проигрыватель (Audiophile Turntable Deck):**
   - **Физический тонарм с микролифтом (Cue Drop):** плавное опускание алмазной иглы на дорожку диска с реалистичным механическим щелчком и нарастанием шороха.
   - **Процедурный генератор винилового звука (Web Audio API):** аналоговый броуновский шум трения иглы о PVC, случайные щелчки пылинок и 52 Гц рокот мотора.
   - **Аппаратный питч-шифтинг 33⅓ ↔ 45 RPM:** переключение скорости разгоняет вращение на +35% и поднимает тональность музыки на +5.19 полутонов в реальном времени.
   - **Интерактивный скретч (Scratch & Inertia):** прямое манипулирование диском с зажатой мышью или пальцем с последующей плавной инерцией вращения.
   - **Ящик с пластинками (Crate Selector):** мгновенная замена диска на вертушке (Michael Jackson, Pink Floyd, Fleetwood Mac, Miles Davis) с динамической сменой цвета полимера и аудиопрофиля.
   - **RIAA Spectrum Analyzer:** 60 FPS канвас-осциллограф с неоновым градиентом частот (20 Гц – 20 кГц).

2. **Энциклопедический исторический кодекс:**
   - **1887 — Истоки:** Изобретение плоского граммофонного диска и никелевых штамповочных матриц Эмилем Берлинером.
   - **1898–1947 — Эра Шеллака:** Диски на 78 об/мин из смолы тропических насекомых.
   - **1948 — Рождение LP:** Доктор Петер Голдмарк и революция микроканавки (Microgroove, Columbia Records).
   - **1949 — Битва скоростей:** 33⅓ RPM против 45 RPM RCA Victor для джукбоксов.
   - **1958 — Стерео Westrex 45/45:** Стандарт двух каналов в единой V-образной канавке Алана Блюмлейна.
   - **Триумф бестселлеров:** Глубокий разбор *Thriller* Майкла Джексона (70M+ копий, технология Acusonic Recording Process).
   - **Гид коллекционера:** Интерактивный калькулятор сохранения фиделити и ценности по шкале Goldmine Standard (Mint, NM, VG+, VG, G).

3. **Дизайн-система (Cyber-Editorial & Acid Neo-Brutalism):**
   - Сетка с тонкими графитовыми разделителями `1px solid #111111`.
   - Тёплый газетный фон `#eae7df` с наложением текстуры шума бумаги.
   - Бруталистские репитер-баннеры с чередованием залитого и контурного шрифта.
   - 4-конечные звёзды-астериски ✦ и неоновые градиенты.

## 🛠 Архитектура и технологии

- **HTML5 Semantic Markup / Canvas API**
- **Modern CSS3:** CSS Custom Properties (Design Tokens), 8pt Grid System, CSS 3D Transforms, Hardware-Accelerated Animations
- **Vanilla ES6+ JavaScript:** Модульная компонентная архитектура, Clean Architecture, Strict Immutability
- **Web Audio API:** Процедурный синтез звуковых волн и фильтрация без сторонних зависимостей
- **Testing:** 12 автоматических unit-тестов (контракты данных, расчет скоростей, DOM-валидация, стандарты ECC)

## 🚀 Локальный запуск

Сайт работает без сборщиков (Webpack/Vite не требуются):
```bash
# Клонировать репозиторий
git clone https://github.com/pahauniti/vinyl-matrix.git
cd vinyl-matrix

# Запустить любой локальный сервер (например, через Python)
python -m http.server 8080
```
Откройте в браузере: `http://localhost:8080`

## 🌐 Развертывание на GitHub Pages

1. Перейдите в настройки репозитория: **Settings → Pages**.
2. В разделе **Build and deployment** выберите:
   - **Source:** Deploy from a branch
   - **Branch:** `main` / `/ (root)`
3. Нажмите **Save**. Сайт станет доступен по адресу:
   `https://pahauniti.github.io/vinyl-matrix/`
